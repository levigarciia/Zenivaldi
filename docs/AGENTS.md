# Desenvolvimento

* Escreva em português brasileiro.
* Use Bun para executar as verificações.
* Nunca inclua perfis, histórico, cookies, preferências pessoais ou backups neste repositório.
* O instalador deve funcionar no Windows PowerShell 5.1 sem dependências adicionais.
* Teste o instalador em uma instalação simulada. Não altere o navegador real durante os testes.
* Ao mudar os scripts de interface, valide também o ciclo de abrir, digitar, executar e reabrir o modal.
* Mudanças no Vivaldi podem alterar seus elementos internos. Documente a versão realmente validada.
